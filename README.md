# ИП Воронин — сайт услуг

Статическая версия сайта, воссозданная на основе оригинала на Wix:  
https://ljubitel.wixsite.com/voronin

## Содержание

- **Главная** (`index.html`) — герой-блок, краткий обзор услуг, автопарк, контакты
- **Услуги** (`services.html`) — подробное описание 4 услуг
- **Автопарк** (`fleet.html`) — 4 Volvo + тентованный прицеп

## Как запустить локально

Просто откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
# Python
python -m http.server 8000

# или Node
npx serve .
```

## Размещение на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите все файлы из этой папки
3. В Settings → Pages выберите ветку `main` и папку `/ (root)`
4. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`
